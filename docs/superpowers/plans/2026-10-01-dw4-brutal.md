# DW4 Very Hard Plus — Brutal (v2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the **Very Hard Plus — Brutal** preset: a committed, verified row→type table plus one transform stage that copies each enemy type's strongest row over every other row of that type.

**Architecture:** Two stages. Stage 1 is data only: a new `rowgroup` module in the engine holds 48 row groups (row indices and model names, no game bytes), verified structurally, against the runtime snapshot it was derived from, and against a real disc's authored table. Stage 2 adds one `PatchPlan` field and one stage in `transform`, then the preset, the GUI surface and the user-facing caveats. No new write mechanism: the collapse is the same whole-row copy the practice buff already performs.

**Tech Stack:** Rust (stable), the existing workspace (`dw4vhp-core`, `dw4vhp-gui`), `memmap2` and `md-5` (already dependencies) for the env-gated checks. **No new dependencies.** Python 3 only for the committed provenance script, which no build or test runs.

**Spec:** `docs/superpowers/specs/2026-10-01-dw4-veryhard-plus-design.md` — §12 is the design this plan implements; §2, §3, §6, §7, §8 and §9 are the parts of v1 it must not break.

## Global Constraints

Copy these verbatim into every task's working set; they override convenience. The first block is inherited from the v1 plan and still applies.

- **No game data in the repo, ever** — no ISO, ELF, memory card, savestate, snapshot or extract, however small. `.gitignore` covers `*.iso`, `*.elf`, `*.p2s`, `*.ps2`. The 32 MB RAM snapshot the table came from stays outside the repo, like the discs.
- **The input ISO is opened read-only and never written.** The output is always a separate file.
- **Rounding is `f64::round_ties_even()`, never `f64::round()`.**
- **Every write is same-length and in place** on the output copy. Nothing grows, moves or is repacked.
- **Every write is gated on a precondition**; when a check fails the app writes nothing and says which check and what to do.
- **Player-facing messages name the fix**, never just the fault.
- **All tests must skip cleanly, not fail, when the real artefacts are absent.** CI has no discs and no snapshot.
- **Retail constants that must not drift:** rows `649`; copies `665`; HP block `0x78D64C5`; stats block `0x78DACB9`; chargen block `0x78DA51D`; block sizes `2596 / 15576 / 1947`; destructible rows `370..=378`; tripwire rows `644, 645`; crown rank `5`; HP cap `400_000`; i16 cap `±32767`; crit/para cap `60`; difficulty vaddr `0x00371DDC`; boot ELF `SLUS_208.36`, length `4_541_744`.
- **Brutal constants that must not drift** (spec §12): the table has **48 groups** — 39 enemy types and 9 `g_*` props — covering **580 rows**; **69** rows are in no group; the collapse skip set is **`638..=645`**; the collapse rewrites **524 rows across 39 multi-row groups**; the nine `g_*` groups are single-row groups at `370..=378`.
- **The row→type table is data, not logic.** `ROW_GROUPS` is transcribed from spec §12.1 and must match it exactly; `tools/rowgroups.py` regenerates it and the snapshot test (Task 2) proves it.
- **Verification gate for every task:** `cargo fmt --all --check` && `cargo clippy --workspace --all-targets -- -D warnings` && `cargo test --workspace` all clean.
- **Lint hygiene, because CI runs `-D warnings`:** assert booleans as `assert!(x)` / `assert!(!x)`; build variants with struct-update syntax (`PatchPlan { collapse_to_top: true, ..Default::default() }`) rather than `Default::default()` followed by field assignment; derive `PartialEq` and `Debug` on every type a test compares.
- **Environment variables for the env-gated tests**, all unset in CI and all skipping cleanly:
  - `DW4_GOLDEN_SHIPPED_ISO`, `DW4_GOLDEN_BLOCKS_BIN`, `DW4_GOLDEN_BLOCKS_JSON` — the v1 golden chain (Task 5), documented in the README;
  - `DW4_GOLDEN_SHIPPED_ISO` alone — the disc cross-check (Task 2);
  - `DW4_ROWGROUP_SNAPSHOT` — the runtime table snapshot the groups came from (Task 2), e.g. `pi-re/snapshots/pink_ram.bin`.
- Crate names and the public API in each task's **Interfaces** block are fixed. `Preset` and `PatchPlan` are exhaustive matches: adding a variant or a field must update every match site (`plan()`, `label()`, `detect()`), and the compiler will say which.

## Review Focus

The five non-obvious failure modes most likely to bite a player or to pass review while being wrong. Each is pinned by a test in the task that owns the code.

1. **A transcribed row wrong** — a row missing, duplicated, or assigned to the neighbouring type. Nothing about the collapse looks broken; some enemies silently get the wrong stats. → the structural tests and the real-disc check in Task 1, and the snapshot equality test in Task 2.
2. **Brutal destroys the tripwire** — the practice pair `644/645` must stay authored (HP 35, no crown) or the 2-player graduation test can no longer identify the row. → Task 3 and Task 5.
3. **The destructibles get collapsed** — `370..=378` must keep breaking normally (HP 100, authored). → Task 3 and Task 5.
4. **Preset identity drifts** — `Preset::Brutal.plan()` must round-trip through `detect()`, and any edit must report `Custom` rather than a named build. → Task 4.
5. **The attack note understates Brutal** — `attack_pinned` is a scaling-time figure (spec §12.2); after the collapse far more rows sit at `32767`, so the app must state the collapse separately instead of letting the note stand alone. → Task 4 (`collapse_note`) and Task 5.

- [ ] **Step 3: Write `tools/rowgroups.py`, and generate the table from it**

The script is the table's provenance: it reads the runtime RAM snapshot and prints the groups. It is committed and never run by a build or a test. Its two outputs must stay in sync with each other and with spec §12.1.

```python
#!/usr/bin/env python3
"""Print the row->type groups for the Brutal preset (spec 12.1).

The disc's three patchable columns are numbers, so the type a row belongs to
exists only in the runtime MODEL column. This reads a RAM snapshot of the
authored table and prints the groups. The offsets are the ones patch_iso.py
uses; tests/rowgroup_snapshot.rs in dw4vhp-core is a Rust port that asserts the
committed ROW_GROUPS matches this derivation.

  python3 tools/rowgroups.py --markdown SNAPSHOT
  python3 tools/rowgroups.py --rust SNAPSHOT

No game data is written; only row indices and model names are printed.
"""
import argparse, collections, struct

DB, ROWS = 0x1748840, 649

def load(path):
    data = open(path, 'rb').read()
    u32 = lambda a: struct.unpack_from('<I', data, a)[0]
    hp = [struct.unpack_from('<i', data, u32(u32(DB + 0x1C) + 0x10) + 4 * r)[0]
          for r in range(ROWS)]

    def model_of(r):
        table = u32(u32(DB + 0x34) + 0x10)
        entry = u32(table + 4 * r)
        if not entry:
            return None
        ptr = u32(entry + 8)
        if not (0x100000 < ptr < 0x2000000):
            return None
        end = data.find(b'\0', ptr, ptr + 64)
        name = data[ptr:end].decode('latin1')
        return name if name and all(32 <= ord(c) < 127 for c in name) else None

    groups = collections.OrderedDict()
    for r in range(ROWS):
        name = model_of(r)
        if name:
            groups.setdefault(name, []).append(r)
    return groups, hp

def ranges(rows):
    out, start, prev = [], rows[0], rows[0]
    for r in rows[1:]:
        if r == prev + 1:
            prev = r
            continue
        out.append(str(start) if start == prev else f'{start}-{prev}')
        start = prev = r
    out.append(str(start) if start == prev else f'{start}-{prev}')
    return ', '.join(out)

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument('snapshot')
    ap.add_argument('--markdown', action='store_true')
    ap.add_argument('--rust', action='store_true')
    args = ap.parse_args()
    groups, hp = load(args.snapshot)
    if args.markdown:
        print('| model | rows | top |')
        print('|---|---|---|')
        for name, rows in groups.items():
            print(f'| `{name}` | {ranges(rows)} | {max(rows, key=lambda r: hp[r])} |')
        return
    print('pub const ROW_GROUPS: &[RowGroup] = &[')
    for name, rows in groups.items():
        top = max(rows, key=lambda r: hp[r])
        body = ', '.join(str(r) for r in rows)
        print(f'    RowGroup {{ model: "{name}", top: {top}, rows: &[{body}] }},')
    print('];')

if __name__ == '__main__':
    main()
```

- [ ] **Step 1: Write the snapshot equality test**

This is an independent Rust port of `tools/rowgroups.py`'s extraction. It must derive the groups from the snapshot and assert they equal `ROW_GROUPS` exactly, including each `top` under the authored-HP criterion.

```rust
// crates/dw4vhp-core/tests/rowgroup_snapshot.rs
//! Proves the committed row groups are the ones the runtime table carries.
//!
//! Skips cleanly unless `DW4_ROWGROUP_SNAPSHOT` points at a RAM snapshot of the
//! authored table (spec §12.1). The snapshot is outside the repository, like
//! the discs: no game data is committed.
use dw4vhp_core::rowgroup::ROW_GROUPS;
use std::path::PathBuf;

const DB: usize = 0x174_8840;
const ROWS: usize = 649;

fn u32_at(bytes: &[u8], at: usize) -> usize {
    u32::from_le_bytes(bytes[at..at + 4].try_into().unwrap()) as usize
}

fn i32_at(bytes: &[u8], at: usize) -> i32 {
    i32::from_le_bytes(bytes[at..at + 4].try_into().unwrap())
}

/// The authored HP of `row`, through the table's i32 container.
fn hp_of(bytes: &[u8], row: usize) -> i32 {
    i32_at(bytes, u32_at(bytes, u32_at(bytes, DB + 0x1C) + 0x10) + 4 * row)
}

/// The `MODEL` string of `row`, or `None` for an unfilled slot.
fn model_of(bytes: &[u8], row: usize) -> Option<String> {
    let table = u32_at(bytes, u32_at(bytes, DB + 0x34) + 0x10);
    let entry = u32_at(bytes, table + 4 * row);
    if entry == 0 {
        return None;
    }
    let name = u32_at(bytes, entry + 8);
    if !(0x10_0000..0x200_0000).contains(&name) || name + 64 > bytes.len() {
        return None;
    }
    let end = bytes[name..name + 64].iter().position(|&b| b == 0)? + name;
    let text = std::str::from_utf8(&bytes[name..end]).ok()?;
    (!text.is_empty()).then(|| text.to_string())
}

#[test]
fn the_committed_groups_are_the_runtime_tables_groups() {
    let Some(path) = std::env::var_os("DW4_ROWGROUP_SNAPSHOT").map(PathBuf::from) else {
        eprintln!("SKIP: DW4_ROWGROUP_SNAPSHOT is not set");
        return;
    };
    let bytes = std::fs::read(&path).unwrap();

    let mut derived: Vec<(String, Vec<usize>)> = Vec::new();
    for row in 0..ROWS {
        let Some(model) = model_of(&bytes, row) else { continue };
        // A type's rows are not adjacent (`e_goburi` is 0-11, 379-393, 638-639),
        // so group by model in first-appearance order, which is first-row order.
        match derived.iter_mut().find(|(name, _)| *name == model) {
            Some((_, rows)) => rows.push(row),
            None => derived.push((model, vec![row])),
        }
    }

    assert_eq!(derived.len(), ROW_GROUPS.len(), "group count");
    for (expected, (model, rows)) in ROW_GROUPS.iter().zip(derived.iter()) {
        assert_eq!(expected.model, model, "group order and names");
        assert_eq!(expected.rows, rows.as_slice(), "{} membership", model);
        let top = rows.iter().copied().max_by_key(|&r| hp_of(&bytes, r)).unwrap();
        assert_eq!(expected.top, top, "{model} top row");
    }
    assert_eq!(ROW_GROUPS.iter().map(|g| g.rows.len()).sum::<usize>(), 580);
}
```

fn the_groups_cover_exactly_the_live_rows_of_a_real_disc() {
    let Some(path) = std::env::var_os("DW4_GOLDEN_SHIPPED_ISO").map(std::path::PathBuf::from)
    else {
        eprintln!("SKIP: DW4_GOLDEN_SHIPPED_ISO is not set");

    let mmap = unsafe { memmap2::Mmap::map(&file).unwrap() };
    let table = dw4vhp_core::table::EnemyTable::read(&mmap[..], &dw4vhp_core::layout::Layout::retail())
        .unwrap();

    let mut covered = vec![false; table.len()];
    for group in ROW_GROUPS {
        for &row in group.rows {
            covered[row] = true;
        }
    }
    for row in 0..table.len() {
        assert_eq!(
            covered[row],
            table.hp[row] > 0,
            "row {row}: covered by a group vs live on the disc"
        );
    }
    for group in ROW_GROUPS {
        let max = group.rows.iter().map(|&r| table.hp[r]).max().unwrap();
        assert_eq!(
            table.hp[group.top], max,
            "{}: top row {} is not a group maximum",
            group.model, group.top
        );
    }
}
